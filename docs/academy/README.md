# Classroom GitHub and Salesforce DX Workflow

This folder records the Week 02 collaboration workflow for the Warehouse Management & Logistics Salesforce DX repository.

Scope for this exercise is documentation only. No Salesforce metadata, Apex, Flow, Lightning Web Component, or business-process functionality is changed.

The companion notes cover source inspection, training-org authentication, a safe documentation update, branching, pull-request review, controlled conflict resolution, and submission evidence.
