# Source Structure Inspection

The repository is a Salesforce DX project. Its package directory is `force-app`, with deployable source below `force-app/main/default`.

Key areas inspected before making the documentation-only change:

- `classes/` for Apex source and tests
- `lwc/` for Lightning Web Components
- `objects/`, `permissionsets/`, `flows/`, and `applications/` for Salesforce metadata
- `scripts/` for local validation and org workflow commands

No source or metadata file in these areas is changed by this classroom workflow branch.
