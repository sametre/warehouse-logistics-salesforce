# Pull Request and Peer Review

The pull request should target `main` and state that its scope is documentation-only.

Review checklist:

- Confirm that only files in `docs/academy/` changed.
- Confirm that no credentials, org IDs, or authorization URLs are included.
- Check that the workflow instructions use the correct project paths and commands.
- Leave feedback in the pull-request conversation, then apply any accepted suggestion in a follow-up commit.

Peer-review evidence is the real GitHub review/comment URL or screenshot attached after a peer completes the review. This document does not claim that a review has already occurred.
