# Submission Evidence Checklist

Before marking the classroom task ready for review, attach or link the real evidence below:

- Pull-request URL for this documentation branch
- Peer-review comment, approval, or review URL
- Merge-conflict resolution commit or GitHub merge record
- Screenshot or terminal output showing a clean final `git status --short --branch`
- Short workflow explanation covering clone, branch, commit, push, pull request, review, merge, and pull

Use the actual GitHub URLs and command output generated during the exercise. Do not substitute placeholders as evidence.
